# Тесты API для Stellar Burgers

Репозиторий содержит автоматизированные тесты API для сервиса Stellar Burgers.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов


### Запуск тестов с генерацией Allure отчёта

```bash
pytest --alluredir=allure-results
```

### Генерация и открытие Allure отчёта

После запуска тестов с генерацией результатов:

```bash
allure serve allure-results
```

## Структура проекта

```
.
├── tests/                      # Тесты
│   ├── test_create_user.py    # Тесты создания пользователя
│   ├── test_login_user.py     # Тесты авторизации
│   ├── test_update_user.py    # Тесты обновления данных пользователя
│   ├── test_create_order.py   # Тесты создания заказа
│   └── test_get_user_orders.py # Тесты получения заказов
├── conftest.py                # Фикстуры pytest
├── pytest.ini                 # Конфигурация pytest
├── requirements.txt           # Зависимости проекта
└── README.md                  # Документация

```

## Описание тестов

### Создание пользователя (TestCreateUser)
- Создание уникального пользователя
- Создание пользователя, который уже зарегистрирован
- Создание пользователя без обязательного поля

### Логин пользователя (TestLoginUser)
- Логин под существующим пользователем
- Логин с неверным логином и паролем

### Изменение данных пользователя (TestUpdateUser)
- Изменение данных с авторизацией
- Изменение данных без авторизации
- Проверка изменения любого поля пользователя

### Создание заказа (TestCreateOrder)
- Создание заказа с авторизацией
- Создание заказа без авторизации
- Создание заказа с ингредиентами
- Создание заказа без ингредиентов
- Создание заказа с неверным хешем ингредиентов

### Получение заказов пользователя (TestGetUserOrders)
- Получение заказов авторизованного пользователя
- Получение заказов неавторизованного пользователя
